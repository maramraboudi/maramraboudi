## 🛠️ Featured Builds

### 🔐 VulnTrack — *EY Tunisia*
Secure vulnerability & compliance management platform replacing manual Excel/email workflows with a centralized, audit-ready system.
- Account-isolated brute-force protection with per-account lockout & admin recovery flow
- Hardened data-ingestion parsers defending against XML-based attack vectors
- Compliance mapping to **ISO 27001** & **SOC 2**, with export logging for audit trails
- **110 automated tests** validating security assumptions pre-deployment

### ☁️ Orchestryx — *Personal Project*
Cloud-native cybersecurity lab platform on AWS that provisions isolated, on-demand hacking environments via web UI.
- Ephemeral infrastructure with vulnerable containerized targets, dedicated VPC, WireGuard VPN access
- Full teardown-after-session lifecycle for isolation, scalability & cost efficiency
- Stack: **Cognito · ECS Fargate · AWS CDK · Aurora Serverless · SQS · Secrets Manager · CloudWatch**

### 📊 SIEM-Based Log Monitoring
Splunk deployment collecting & analyzing Linux server security logs — brute-force detection, alerting, and documented IR workflow.

### 🕸️ Web Application Penetration Testing
DVWA-based lab exploiting SQLi, XSS & CSRF, with OWASP Top 10-aligned remediation reporting.
